# Sprites de referência — projeto de estudo

Atlases derivados das sprite sheets de **Digimon World DS**, disponibilizadas no The Spriters Resource. O tratamento separa os quadros usados e remove o fundo das folhas.

| Personagem   | Fonte                                                             | Créditos na folha              |
| ------------ | ----------------------------------------------------------------- | ------------------------------ |
| Agumon       | https://www.spriters-resource.com/ds_dsi/dgmnworldds/asset/48418/ | Mighty Jetters / redblueyellow |
| Betamon      | https://www.spriters-resource.com/ds_dsi/dgmnworldds/asset/48421/ | Mighty Jetters / redblueyellow |
| Greymon      | https://www.spriters-resource.com/ds_dsi/dgmnworldds/asset/48406/ | A.J. Nitro / redblueyellow     |
| MetalGreymon | https://www.spriters-resource.com/ds_dsi/dgmnworldds/asset/48322/ | RadsPyro                       |
| WarGreymon   | https://www.spriters-resource.com/ds_dsi/dgmnworldds/asset/48613/ | A.J. Nitro / redblueyellow     |

Digimon, seus personagens e sprites pertencem aos respectivos titulares. Esses assets não são apresentados como conteúdo original ou sob uma licença livre. O projeto é uma experiência de estudo, sem afiliação oficial. A seleção e o alinhamento de quadros ainda precisam de refinamento.
